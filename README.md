# Gamer Boyz

A handheld-console-styled auto-running side-scroller starring **Tone Da Boss** and **Entre Luché**, synced to the song "Gamer Boyz."

- Jump enemies, collect Records, and race to the flagpole as the song plays
- 1P (Entre is CPU) or 2P (A = Tone, B = Entre)
- Pause menu with pre-save and social links

## Files
- `index.html` — the whole game (HTML, CSS, JS)
- `cover.jpg` — cartridge cover art
- `gamerboyz.mp3` — the song

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.

## Deploy
Static site — no build step. Deploys as-is on Vercel.
